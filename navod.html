Návod: Identifikácia chýbajúceho pravidla triedenia

1 Krok 1 → Získanie ID zásielky
Otvoríme si modul Zásielky. Podľa čísla si vyfiltrujeme hľadaný balík. Zaujíma nás hodnota zo stĺpca ShipmentPackageContainer_ID.
Obrázok 1: Vyhľadanie ID zásielky v systéme
2 Krok 2 → Report z chyby
Použijeme modul Administrace systému, záložka SQL Errors. Do objektu zafiltrujeme získanú hodnotu ShipmentPackageContainer_ID. Kontrolujeme, že procedúra je dbo.Unloading_LocationForPackage_GET. Taktiež skontrolujeme presný čas vzniku chyby.
Obrázok 2: Identifikácia správneho SQL logu
3 Krok 3 → Text pre aplikáciu
Po dohľadaní správneho riadku si skopírujeme celý text zo stĺpčeka Poznámka. Tento text obsahuje kompletné parametre pre analýzu.
4 Krok 4 → Získanie ID pre triedenie
Otvoríme si v prehliadači aplikáciu:
https://triedenie-vykladka-quftfvvcufxaffr2ansmzg.streamlit.app/

Do poľa "Vložte chybovú správu" vložíme skopírovaný text a potvrdíme (CTRL+ENTER). Získame informácie o ID sorting type, type triedenia a prípadne navrhnutej lokácii.
Obrázok 3: Analýza údajov v Streamlit aplikácii
5 Krok 5 → Dohľadanie druhu triedenia
V číselníku LL872 vyhľadáme riadok, kde sa Klíč zhoduje so získaným ID. Týmto zistíme konkrétne chýbajúce pravidlo, ktoré je potrebné nastaviť.
